# CH 公开生成数据多分类探索基准（2026-10-02）

本次运行使用作者发布并已校验入库的 CH-BatteryGen 数据，来源是 `public_generated`，命名空间是 `demo_synthetic`。它与本项目通过 LLM 构造的 `expert_synthetic` 数据分开统计。原始生成母体身份不可得；保守共享 VIN 根只能减少已知的片段/化学体系重叠，不能证明干净的源独立性。所有结果只支持公开生成样本上的探索分析，不支持真实车队泛化或物理故障确诊。

执行固定预注册配置，没有调参：

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
.venv/bin/python -m model_lab.scripts.v2.benchmark_generated \
  --config model_lab/configs/generated_fault_v2.yaml \
  --allow-exploratory-final
```

三个种子为 `0, 1, 2`，均执行完成。LFP/NCM 各自拟合 GBDT，输入仅为作者数据的 16 个原生数值均值/标准差；中位数填补及树参数只拟合训练集，温度校准只拟合隔离的校准集。没有使用总体准确率作为主要结论。

总计 96 个片段、48 个保守共享 VIN 根，四类各 24 个片段/12 个 VIN 根。每个化学体系每个 VIN 取冻结的首个充电片段；合并分数先平均共享根的两种化学体系概率，因此 dev/final 各按 7 个 VIN 计算，不能按 14 个独立车辆计算。

宏 AUPRC 仅平均同时具有正、负 VIN 的可评价类别。dev 没有高内阻，final 没有正常类，所以这两个分区的“完整四分类宏 AUPRC”均为 `null`。final 通过显式参数打开，只作为探索证据，不参与选择。下面的标准差来自三个随机种子，不能解释为独立 VIN 的置信区间。

## 验证与产物

- 10 个自动化测试全部通过（1.29 秒）；它们只使用小型玩具夹具验证分区隔离、来源区分、未知类别拒绝、缺失类别指标、VIN 去重、JSON 树拓扑/类型校验和默认最终集封闭策略。玩具夹具不能作为真实来源训练证据。
- 实际数据运行前重新核对三张 Parquet 表的 SHA256、行数、来源和冻结共享根分区。实际来源的计数与推理证据保存在 `inference_validation.json`。
- 每次拟合在内存中检查数值 JSON 模型与 sklearn 原模型概率一致（容差 1e-9），否则运行直接失败。CLI 用落盘后重新读入的 JSON 数值配方评分，不加载 pickle/joblib。
- 完成后重新读入所有三个落盘模型，复算 train/dev/探索 final 的全部首片段预测及指标，与保存结果逐项一致；最大概率绝对误差为 0。训练、校准、dev、final 的保守根集合相互独立。此检查不解决未知生成母体造成的独立性限制。
- 原始成员 SHA256 另行检查：96 个发布片段对应 95 个不同字节内容，唯一重复为训练集内 NCM 低容量 `vin_75` / `vin_79`，没有发现完全相同原始成员跨分区。保留原冻结划分与训练，没有据此重调结果；字节去重也无法恢复未知母体身份。

产物均位于本目录：

- `summary.json`：固定配置、数据摘要、三个种子指标及均值/标准差。
- `inference_validation.json`：实际来源的类别/VIN 计数、三个模型 SHA256、校准参数、分区隔离和推理重放验证。
- `seed0/model.json`、`seed1/model.json`、`seed2/model.json`：独立化学体系的安全数值树配方与校准参数。
- 各种子目录的 `metrics.json`、`landmark_predictions.json`：逐类支持数、AUPRC/校准指标及可重放的 VIN 概率。
