# 首轮模型研发执行与验收

日期：2026-09-25。范围仅限新增 `model_lab/`，未修改旧前后端、数据库、需求文档或已有权重；未提交/推送 Git。

## 1. 数据已经拿到什么

XJTU 官方 V1 压缩包：2,438,769,934 bytes，MD5 `a635cef9678e0de21f9d5c1f78a4342c`，SHA-256 `009deeda5ca935bf7b6230497aa492db12af120b6fc5211a9af05352affe55b1`。完整下载、官方 MD5 校验和安全解压均已完成。

解压包含 55 个独立电芯文件，6 个批次分别为 8、15、8、8、8、8 个；另有 `Temperature_Compensation_Data.mat`，不能把它算作第 56 颗电芯。已实际读取 `Batch-1/2C_battery-1.mat`：390 个循环，首个循环包含 24,444 个采样点。确认 `relative_time_min` 的单位为分钟，以及电压、电流、容量、温度等字段。此检查不代表已完成全部电芯的质量/标签验收。

训练使用的是 PINN4SOH 原作者仓库 commit `cc3cc5053caf38f04e0665f7f88cb109144d035e` 中 5 个 `2C_battery-*.csv` 派生数据，共 607,594 bytes。它们不是另一批独立实验，也不是这轮已经实现的原始波形输入。标签 provenance 暂为 unknown，不将指标宣传成实测容量精度。

HUST、MATR 尚未下载；其他外部来源尚未训练或测试。

## 2. 已实际实现并运行

Python 3.12 隔离环境；数据来源清单和安全下载/解压工具；显式特征白名单；电芯级划分；训练集拟合的缺失处理/标准化；按需历史窗口；当前 MLP、匹配信息 MLP、CPMLP-like 对照和特征版 CADA-v0；经典回归/树模型对照；权重、日志和逐样本预测保存。

CADA-v0 使用当前特征、同电芯早期参考差分、因果卷积历史和历史可用性门控。当前门控不代表已实现真实工况条件化；原始波形编码器、TabM 和完整工况条件化尚未实现。CPMLP-like 不是原论文的严格复现。

主助手修复了三项验收问题：断点续传不再因服务器忽略 Range 而删除已有 partial；训练报告现在重新加载最佳验证权重，而不是报告最后一轮；经典模型现在保存为本项目生成的 joblib 文件。第二轮所有神经模型统一采用仅训练电芯拟合的目标标准化。

## 3. 最新开发对照

3 个训练电芯、1 个验证电芯、1 个封存测试电芯；383 个验证循环样本；1 seed；神经模型训练 30 epochs。报告路径：`reports/dev_run_scaled_30epochs/summary.json`。此轮通过主机受管命令实际使用 MPS；早先 Codex 执行环境报告 MPS 不可用并使用 CPU，不能混写。

| 模型 | 验证 MAE（SOH 百分点） | 验证 RMSE（SOH 百分点） |
|---|---:|---:|
| 均值预测 | 4.583921 | 5.561333 |
| Ridge | 1.180653 | 1.349240 |
| HistGradientBoosting | 0.988551 | 1.125448 |
| ExtraTrees | 1.001789 | 1.206228 |
| 当前特征 MLP | 0.756548 | 1.128646 |
| 匹配信息 MLP | 1.115152 | 1.311713 |
| CPMLP-like | 0.926028 | 1.071828 |
| CADA-v0 | 1.051712 | 1.172272 |

主助手独立重算全部 CSV 指标，核对原始派生文件哈希、训练代码哈希、电芯集合不相交，并验证报告与最佳 epoch 指标一致。CADA 的最佳权重在 CPU 重新加载后的 MAE 为 1.05171258，与 MPS 记录一致。15 项单元测试通过。

首轮 3 epochs 的结果保留于 `reports/dev_run/`。两轮间同时改变了目标标准化、训练轮数与检查点报告逻辑，不能将误差变化归因于模型结构创新。

**验收结论：执行链路可复现；“新颖且显著更好”的模型目标尚未达到。** 不接受 CADA-v0 为最终优胜模型，也不以这一个验证电芯证明普通 MLP 在全部来源上最优。未知 provenance 标签、单电芯验证和短开发试验都限制结论。测试集没有用于调参或报告成绩。
