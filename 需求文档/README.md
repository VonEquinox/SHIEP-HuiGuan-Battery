# 慧管电池接手需求文档

版本：v0.2（按现有实现重新排序，2026-09-25）

## 项目核心

当前可核实的核心是**基于仓库自带实验电池数据的 SOH 模型实验平台**：查看电池循环数据，训练 Baseline/BiLSTM/DeepHPM 候选模型，管理模型与训练记录，在独立样本上测试、比较，并保存可追溯的预测结果。`RUL_Flt`、`PCL_Flt` 是数据文件中的标签；现有 Web 训练代码主要训练 SOH 相关目标，不能因此宣称已经实现可靠的 RUL/PCL 联合预测。

训练来源是 `SeversonBattery.mat`。MySQL 中的实验电池与循环记录是其导入结果，不是第二个独立来源。仓库没有给出该加工文件相对公开 Severson 原始数据的处理脚本或字段字典；导入代码还**假设**八个特征的物理含义。所谓秒级 BMS 是模拟器，部分数据表、测试曲线、大屏和派单页面也使用随机或固定数据。当前没有证据证明系统接入了真实园区储能柜。

## 优先级口径

这里的优先级表示**接手后先把什么做成可靠产品**，不是说遗留功能已经通过验收。

| 级别 | 判定原则 | 本项目范围 |
| --- | --- | --- |
| P0 核心 | 有本地数据、训练或查询代码作为基础，直接支撑模型实验结论 | 实验数据来源与字段核验、数据查看、训练、模型登记、独立测试、指标与预测记录、最小登录权限 |
| P1 已搭界面/接口的扩展 | 代码或页面存在，但关键数据与行为主要是模拟、固定值或未连通 | 展示大屏、电芯风险页、实验性告警与工单、减碳情景、分享与后台管理；先改成诚实的实验/演示模式 |
| P2 新业务 | 现有交付无法证明具备数据和业务条件 | 真实 BMS 接入、园区资产体系、生产告警与现场工单闭环、移动端、可核证减排 |

P0 内按依赖顺序实施：**核实数据与标签 → 可复现训练 → 独立评估 → 可信预测记录 → 可读的模型比较界面**。现有预测页即使可点，也不能越过数据和模型验证直接作为生产预测。
