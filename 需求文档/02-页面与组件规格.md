# 页面与组件规格

本文按接手优先级列出**每个现有页面/服务组件应承担的职责**。旧页面名仅用于定位代码；页面存在不代表数据或操作可信。P0 页面默认有加载、空、失败、无权限状态，数据来源、单位和更新时间要可见。

## 1. P0 实验平台页面

| 页面/组件（现有对应） | 核心职责 | 输入与动作 | 结果与验收 |
| --- | --- | --- | --- |
| 登录与实验工作区（`Login.vue`、`App.vue`） | 识别实验成员并进入数据、训练、测试、模型、结果五个工作区 | 登录、退出、导航；保留所选数据集/模型上下文 | 后端校验操作权限；无固定密码绕过；服务失败不显示伪成功。 |
| 数据集概览（`TestData.vue` 占位） | 告诉用户现在用的是什么数据 | 展示源文件、哈希、版本、实验电芯数、划分数、标签和字段字典 | 未知字段明确标“待核实”；不能以固定文案代替文件检查。 |
| 数据管理（`DataManagement.vue`） | 查看实验电池与循环记录，检查数据质量 | 按电芯、训练/验证/测试划分、循环区间筛选；查看特征/标签趋势；导出所选范围 | 表格与图来自相同真实记录；不生成随机行、随机曲线或固定总数。 |
| 训练平台（`TrainPlatform.vue`） | 创建和监控 SOH 候选模型训练任务 | 选 Baseline/BiLSTM/DeepHPM、数据版本、参数；启动、查看状态、日志与指标 | 页面任务状态与服务端一致；显示失败原因、训练与验证指标；完成才可进入模型列表。 |
| 模型管理（`ModelManagement.vue`） | 查找、比较、选择、停用实验模型 | 查看算法、版本、目标、特征、训练数据、权重状态、验证指标；选择用于测试 | 模型文件不存在/损坏时明确不可用；API 失败不回退成模拟模型。 |
| 独立测试平台（`TestPlatform.vue`） | 用保留电芯和真实标签评估模型 | 选模型与测试集/电芯、运行测试、查看每循环真值与预测、导出结果 | 真值来自数据集，预测由模型计算；指标与逐样本数据一致，禁止 `Math.random()` 造精度。 |
| 结果分析（`ResultsAnalysis.vue`） | 聚合实验报告与模型对比 | 按模型、实验批次、测试集筛选误差、收敛、分布、样本数 | 每张图链接训练/测试记录；无结果显示空状态，不填随机曲线。 |
| 预测记录和实际值（`UpdateActualValue.vue`） | 追溯单次推理与后续真值 | 查看输入快照、模型版本、输出、状态；录入有来源的实际值 | 保留原预测；记录回填来源、操作者和时间；无真值不计算精度。 |

### P0 页面间的主路径

`数据集概览 → 数据管理 → 训练平台 → 模型管理 → 独立测试 → 结果分析/预测记录`。所有页面使用同一数据集和模型 ID；从模型详情可以进入其训练日志与测试结果，从测试结果可以回到样本数据。训练错误和权重缺失必须停在可解释的失败状态。

## 2. P0 服务端组件

| 服务组件（现有对应） | 职责 | 必须补齐的边界 |
| --- | --- | --- |
| 数据加载与导入（`functions.py`、`import_data_to_mysql.py`） | 读取 `.mat`、保持电芯级划分、提供可查询的实验样本 | 字段顺序不能靠猜；入库前校验数量、数组对齐、单位与标签；保留源文件哈希。 |
| 电池数据 API（`api/batteries.py`） | 返回实验电池列表和逐循环数据 | 明确数据集/划分、字段字典、分页、单位和质量状态；未知物理含义不能误标。 |
| 训练任务（`api/training.py`） | 执行候选算法训练并保存日志、参数、权重 | 数据版本、随机种子、训练电芯、标准化器和代码版本可追溯；失败不留“成功”模型。 |
| 模型注册（`api/models.py`） | 管理模型元数据、权重及可用状态 | 校验权重和输入特征兼容性；历史结果仍指向原模型版本。 |
| 评估与比较（`api/model_comparison.py`、`api/analysis.py`） | 对同一保留测试集计算逐样本误差和聚合指标 | 指标和图表不能接收客户端伪造真值；必须带测试数据版本、样本数和指标定义。 |
| 预测记录（`api/prediction.py`） | 调用兼容模型推理、保存结果、支持有来源的真值回填 | 前端不能传入“预测值”跳过模型；无输入/权重/推理失败时记失败，不能填常数。 |
| 身份（`api/auth.py`） | 登录与服务端实验操作授权 | 移除特定账号口令绕过，密钥走配置，操作记录能归属用户。 |

## 3. P1 原型与演示页面

| 页面/组件（现有对应） | 保留价值 | 边界与最低要求 |
| --- | --- | --- |
| 仪表板（`Dashboard.vue`、`api/dashboard.py`） | 展示实验项目状态或单独的储能柜概念演示 | 实验统计连接 P0 结果；随机生成柜、电芯和 K 线只能在明确标注的演示模式展示。 |
| 电芯预测页（`CellPrediction.vue`） | 展示所选实验电芯的 SOH 曲线及研究性风险 | 明确电芯是实验样本；等级有规则和阈值来源；不映射虚构现场位置。 |
| 告警/工单（`WorkOrder.vue`、`api/work_orders.py`） | 演示“异常→处理”的交互意图 | 无真实园区设备和工人时仅演示；服务端保存状态，随机推荐人和 `localStorage` 照片不能当现场履约。 |
| 减碳情景（`CarbonCalculation.vue`、`api/carbon_calculation.py`） | 演示两类估算公式 | 输入参数/固定因子与假设清楚可见；报告写“情景估算”，不写实际减排。 |
| 分享管理（`ShareManagement.vue`、`api/shares.py`） | 分享实验模型或数据资源 | 仅分享确实存在且授权可读的对象；失效/撤销须由服务端执行。 |
| 管理后台（`AdminPanel.vue`、`api/users.py`） | 管理实验成员及角色 | 先满足 P0 最小权限；模拟用户列表不得在真实管理模式出现。 |

## 4. P2 尚无可靠基础的组件

若后续转成真正的储能运维系统，才增加资产建档（园区→柜→模组→电芯）、真实 BMS 网关、实时数据质量、生产告警、工单状态机、现场移动端、通知与审计、可核证碳报告。这些需要业主提供设备、协议、现场流程和责任人；当前 P0/P1 页面不能直接作为其验收证据。
