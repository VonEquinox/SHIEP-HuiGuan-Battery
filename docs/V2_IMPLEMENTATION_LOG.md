## 实施边界与证据

开发协作可以使用多个 Agent；产品运行时只使用一个固定流程 Agent。云端 LLM 通过
OpenAI 兼容接口调用，数值模型训练独立于上下文进化。合成与真实实验命名空间隔离，
隐藏 oracle、封存测试和 Carbon fixture 不发布到 Agent 知识库。保护 XJTU 测试电芯不参加开发。

用户提供的测试凭据只在本机临时运行环境使用；Git 仅包含空配置示例。外网请求优先使用
`http://127.0.0.1:7897`。Python 安装通过根目录 `pyproject.toml`、`uv.lock` 和一键安装脚本复现。

每个模块另有实施说明，记录接口、命令、真实结果和限制；本记录在每次提交前更新。
下文只记录实际完成的工作，未执行的真实数据/设备/微信验证不会写成通过。
