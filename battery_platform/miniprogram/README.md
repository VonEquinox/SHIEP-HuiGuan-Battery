# 慧管电池 TEST 微信小程序

在微信开发者工具导入本目录，使用平台实际分配的测试/开发 AppID。仓库里的 AppID 留空，不伪造账号或保证测试号真机能力。

先运行 `npm test` 和 `npm run check`（Node 18+，零 npm 第三方依赖），再运行 `npm run probe` 检测本机开发者工具。提供实际公共配置后，可执行 `npm run configure -- --appid wx实际AppID --api https://实际测试域名`。配置脚本只接受 AppID 和公共 HTTPS 地址，不接受 AppSecret、密码、LLM Key。

后端使用独立 demo 目录，显式设置 `BATTERY_DEMO_MOBILE=1`。在 Web/CLI 创建技术员账号，由调度员批准工作提案并完成排程。登录页填写该平台技术员账号，不使用真实微信授权替代品。实际账号创建与服务启动步骤见项目运行文档。

手机访问可达 HTTPS 后端，在实际微信平台配置 request/uploadFile/downloadFile 对应域名和 TLS。默认 `urlCheck=true`。电脑和手机的 `127.0.0.1` 不是同一服务地址；本工程没有自动公开部署、隧道或关闭全局域名校验的脚本。

现场流程：登录 → 本人任务 → 接单/开始 → 服务器签名二维码核验 → 本轮授权检查 → 结构化与自由反馈、照片 → 待同步队列 → Agent 新报告 → 完成本轮 → 处理说明 → 另一角色在 Web 独立验收。Carbon 不属于此小程序。

离线草稿按环境与账号隔离；照片复制到小程序用户目录。观察/轮次提交 UUID 和请求体在重试中保持一致。409 进入冲突状态，先获取服务器记录再明确合并，新提交保留旧草稿。安装身份/轮次改变时禁止合并。照片上传中断时核对已有附件，避免盲目重复上传。账号退出不会冒称草稿已同步；重新登录相同账号可继续。

完整实现、检查命令、环境探针结果与尚未完成的真机验收见 `../docs/V2_MINIPROGRAM_IMPLEMENTATION.md`。
