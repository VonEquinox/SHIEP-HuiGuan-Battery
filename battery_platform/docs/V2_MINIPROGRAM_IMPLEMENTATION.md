# 慧管电池 V2：TEST 微信小程序实施记录

本独立文档记录总方案第 13 节的小程序实施。用户授权多 Agent 完成方案内容；正式上线、账号能力、真实微信身份、生产设备控制不属于本次测试工程。分阶段 Git 提交由根协作 Agent 统一完成。

## 已实现

`battery_platform/miniprogram/` 是原生微信小程序工程，7 个页面：环境/测试登录、本人任务、工单、扫码确认、本轮检查、往返诊断、本地待同步。无 npm 运行依赖，Node 标准库提供测试和工程检查。

- 登录调用 `/api/v2/demo-mobile/login`，使用真实创建的有限技术员测试账号；Bearer 只保存在运行内存，服务端有效期/撤销仍生效。客户端没有角色选择、AppSecret、LLM Key 或硬编码账号密码。
- 任务调用 `/api/orders`，本人范围由服务器确定；按状态筛选、截止排序和 15 秒站内轮询。当前 V1 列表最多 300 项，达到上限时显示提示，未伪装成完整分页。
- 接单、开始、拒绝与处理完成调用 V1 transition 并提交服务器版本。独立验收只显示事件与状态，没有本人验收操作。
- V2 inspection 读取工单授权集合、开放轮次、资产/当前安装身份、观察、附件和报告。填写页取开放轮次的 authorized_tests；需要额外授权的检查不进入可执行下拉框。
- 二维码原样提交 `/qr/verify`，签名/有效期/安装身份/工单访问权由服务器校验。相机不可用可粘贴调度员签名引用，没有客户端签名秘密，不用手填安装编号替代验证。
- 观察提供测量指标/数值/单位/方法、含时区测量时间、仪表和校准状态、执行结果、来源、症状/动作/支持/排除/未知、断言位置与自由原文。0 保留为合法数值；缺测不伪造 0；无实际观察可选择无区分力、失败、超量程、拒绝或需授权。
- PNG/JPEG 照片先校验大小/像素和类型并复制到持久用户目录，再通过 V1 attachment 上传。相机拒绝可用文件选择或文字输入；必需照片不能被文字冒充。没有 V2 授权集合的 V1 工单仍可上传本次证据，不伪造轮次。
- 观察与轮次提交进入本机队列，分别调用 `/observations` 和 `/rounds/{n}/submit`；服务器回复后才能显示已接收。重判进度通过获派诊断的 `/agent/runs/{id}` 读取；新报告、仍未知内容、原文、候选抽取与下一步建议可见。候选抽取保留 reported 含义。

## 离线、幂等与冲突

草稿和队列使用“HTTPS 环境地址 + 服务端用户 ID”命名空间，不跨账号/环境自动读取。观察/轮次 `client_submission_id` 在首次发送与网络重试中保持一致，照片的客户端 ID 也保持一致；完成附件上传后冻结实际发送 payload，丢响应后重试相同内容。一个同步任务在同一时刻只运行一次，同工单前序冲突会阻止后序轮次越过。

网络/429/5xx 错误保留队列并设置指数退避；已登录且联网时按下一重试时间自动尝试，断网暂停，重连或再次登录恢复。401/403/422 进入待处理状态，409 进入冲突状态，均不无限重试。核对服务器已到达观察之后可保留原内容创建新版本提交，旧记录标 superseded 并保留；也可恢复未提交表单修改缺字段/单位等错误。安装身份或开放轮次改变时拒绝合并。

照片上传响应中断有独立 `upload_uncertain` 状态。先读取当前工单附件，人工确认复用已有附件 ID，或核对不存在后恢复同文件 ID 上传；不会自动盲重传。后端已集成可选 `Idempotency-Key`，按账号、工单、文件名、大小、类型和 SHA256 校验并重放同一附件 ID；同键不同内容返回冲突。

本机照片和同步历史当前保留在设备上便于恢复，不充当服务器证据库。账号退出后需重新登录才能读取其队列；未同步草稿不得在业务上标为已完成。
